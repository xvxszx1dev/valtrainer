픽창 도우미 다운로드

⚠ 다운로드 전 꼭 확인하세요
  • 이 프로그램은 .exe 실행 파일이며, Windows PC에서만 동작합니다.
  • 서명되지 않은 개인 제작 프로그램이라 Windows Defender/브라우저에서 경고가 뜰 수 있어요. "추가 정보 → 실행"을 눌러 진행하면 됩니다.
  • 구글 드라이브 특성상 "바이러스를 검사할 수 없습니다" 확인 화면이 뜰 수 있어요. 이 경우 "다운로드 유지/무시하고 다운로드"를 눌러주세요.
  • 본인 책임 하에 사용해주세요. 신뢰할 수 없는 출처에서 재배포된 파일은 실행하지 마세요.
픽창 도우미란? 발로란트 픽창(에이전트 선택 화면)에서 팀원 랭크 확인(단, 경쟁에서 가능 경쟁 외 모드는 언랭으로 뜸), 닷지 버튼 등을 제공하는 로컬 데스크톱 프로그램이에요.
⬇ 다운로드 (.exe)
클릭 시 구글 드라이브를 통해 다운로드가 시작돼요.
